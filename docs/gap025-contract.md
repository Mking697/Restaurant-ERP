## New HTTP contract

All writes same-origin/authenticated mutate; reads locked with live authority. Next params awaited. No standalone FINAL issue endpoint.

- POST /api/pos/documents/proforma {sourceType:'DRAFT'|'ORDER',sourceId:string,expectedRevision:number,requestKey:string} -> {document:Document,replayed?:true}; initial201/replay200.
- GET /api/pos/documents?branchId=<Owner optional>&sourceType=DRAFT|ORDER&sourceId=<optional paired source> -> {documents:DocumentSummary[],visibilityScope:'actual'|'access-filtered',limit:200,truncated:boolean,legacyNotice:string}. Optional sourceType/sourceId must be supplied together; preserve read-only legacy warning when no document exists.
- GET /api/pos/documents/[id] -> {document:Document}; immutable saved content after current target authorization.

Document = {id,branchId,kind:'PROFORMA'|'FINAL',number,issuedAt,sourceType:'DRAFT'|'ORDER',sourceId,sourceRevision,orderId:string|null,proformaId:string|null,receiptNumber:string|null,seller:{name,branchName,branchCode,address,tin:null,vrn:null},customer:{name,phone}|null,orderNumber:string|null,tableNo,channel,lines:[{orderLineId?:string,menuItemId,name,productCode,qty,price,vatRatePercent,lineTotal}],subtotal,taxAmount,totalAmount,vat:{rates:[{ratePercent,taxableAmount,vatAmount}],grandTaxable,grandTotalTax,grandTotal},currency:{baseCode:'TZS',tenderCurrencyCode,fxRateToInr,tenderCurrencyAmount},disclaimer:string}.

DocumentSummary = subset id,branchId,kind,number,issuedAt,sourceType,sourceId,sourceRevision,orderId,proformaId,receiptNumber,totalAmount,currency. DTOs NEVER contain stored request keys/request JSON or authority internals. Pure shared types live src/lib/pos-documents.ts (no DB import).

Backend exports issueFinalPosDocument(tx,actor,orderId,context?:{draftId:string;draftRevision:number}) -> {document:Document|null,unavailableReason?:string}. Called only internally after PAID+receipt persistence, before saved action acknowledgment; createPosOrder gains optional internal fifth context argument; dispatch passes it. Existing success result may add finalDocument/documentUnavailableReason without changing existing receipt schema.
