What's next

Everything in the 22 modules above is live and ready to use today. A short, honest list of what is genuinely still outside current scope follows — so staff know what to expect and what not to expect yet.

Customer membership, rewards and QR cards
Voluntary WhatsApp community invitation; membership registry with explicit consent; append-only reward earn/redeem/expire/reverse ledger; opaque revocable member QR; safe repeat ordering using current availability, prices and taxes. A captured phone number alone is not consent or membership — this entire area has no screen in the app yet.
Known current-scope boundaries
Image-based touch menu for POS; live Swiggy/Zomato provider API intake (aggregator orders are recorded as a channel today, not a connected provider integration); split-tender/part-payment on a single order; prepared-stock physical count history; fixed-recipe actual lot cost carry-through; partial vendor-payment allocation; broader non-quality vendor return reasons; mid-shift cash top-up/withdrawal as a distinct movement type beyond linked expenses.
