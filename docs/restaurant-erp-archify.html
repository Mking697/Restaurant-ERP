🍽️ Restaurant HQ — ERP + WhatsApp Automation

Neeche har box ek module hai — jo ERP ke andar ek screen/feature represent karta hai. Kisi bhi box par click karo — wahan uska pura explanation khulega: wo kya karta hai, kaise use hota hai, aur ek real example ke saath. Isse koi bhi layman — jisko coding/ERP ka kuch pata nahi — pura system samajh sakta hai.

Live DB = real login + real Postgres database + branch isolation ab actually kaam karta hai (Owner sabhi branches, Branch Admin sirf apni, user sirf apna module access). Pending = abhi demo/placeholder data hai, apni asli DB integration ka wait kar raha hai — app mein login karne par yeh modules ek saaf "DB integration pending" panel dikhate hain, kabhi purana demo data branch-filtered dikha kar confuse nahi karte.
